# Screenleap

> Screenleap provides an API to add live screen sharing, video conferencing, audio conferencing and chat to websites and online products. Server-to-server REST/JSON creates a session; a hosted screenleap.js loader drives the presenter and a returned viewer URL renders the share to viewers. Billing is per-participant-minute with no subscription required.

## API
- [Screen Sharing API overview](https://www.screenleap.com/api): What the API does and how to add screen sharing to a site.
- [HTTP Calls reference](https://www.screenleap.com/api/native/doc/http-calls): The five REST endpoints (create/get/list/recent/stop screen shares).
- [Quick Start Guide](https://www.screenleap.com/api/native/quick-start): Minimal integration walkthrough.
- [Presenter integration](https://www.screenleap.com/api/v2/presenter): Loading screenleap.js and starting a share.
- [Viewer integration](https://www.screenleap.com/api/v1/viewer): Redirect or iframe-embed the viewer URL.
